Rules in, messages out.

Write each field's rules as a small object. FormValidator checks them in a fixed order, puts the first failure under or beside the field, and submits the form behind its own loader. Leave a field, or press Create account.

03Formatters

        

            FormValidator.format is static: no instance, no initialize().
        

        

            

                
1,234.5

                
currencyField(number, sep)

                
Groups the whole part only, keeps the sign and the decimals, and returns a string.

                

                    
                    
                

                

            

            

                
1.01

                
roundToDec(value, decimals)

                
Rounds through exponent notation, so 1.005 becomes 1.01, not 1.

                

                    
                    
                

                

            

            

                
0-9

                
integerField(input)

                
Strips every non-digit as it is typed. Paste +1 (555) 010-99 and see.

On blur, joins the words with the separator repeated n times. Here "-", twice.

04Misuse throws

        

            The constructor, every setter and every method check their arguments. Each button runs one bad
            call on a fresh validator and prints what it threw.
        

        

        
No error yet. Press one of the buttons above.

        

            Two checks are lazy, and the last two buttons show it: validate() checks
            location only when it writes a message, and a size rule is parsed only when a file is chosen.
