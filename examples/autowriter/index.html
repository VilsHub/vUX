02Directives

        

            Three sequences are read as instructions instead of being typed. Everything else goes in literally.
        

        

            

                
|

                
Line break

                
Inserts a real <br>. It counts as one erasable unit, so backspacing through it removes the break whole.

                

                
            

            

                
*n*

                
Backspace

                
Deletes n units at typing speed, then carries on with the rest of the string. Sequenced, never racing.

                

                
            

            

                
~n~

                
Pause

                
Waits n milliseconds. The caret blinks while it waits, which is the only time it blinks.

                

                
            

        

    






    

        
03One call, many elements

        

            Hand writeText() a NodeList and a matching array of strings and they type
            in sequence — each starts when the last finishes. The callback runs once, at the end.

04Bad input fails immediately

        

            Directives are checked when writeText() is called, not when they are reached — so a typo
            throws to your code straight away instead of failing seconds later inside a timer.
