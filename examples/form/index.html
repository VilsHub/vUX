02Two attribute conventions

This trips people up, so the example uses both deliberately. select and datePicker take the full attribute name; slideSwitch and file take dataset names without the data- prefix.

1

Full attribute name

The value is the attribute exactly as written in the markup.

select.config.sizeAttribute = "data-size";
// <select data-size="230px,40px">
2

Dataset name

The prefix is implied; give the key as it appears on element.dataset.

slideSwitch.config.dataAttributeNames = { size: "dim" };
// <input data-dim="70px,30px">
↻

Content added later

New markup is not converted automatically. refreshSelect(native) rebuilds one widget; refresh(container) converts whatever is new inside a container.

Both buttons in section 01 do exactly this.
