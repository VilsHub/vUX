vUX / TimeLineList / v4.0.0-beta

Any list, drawn as a timeline.

Give a plain <ul> a class and a few data attributes. TimeLineList draws the rail, the markers and the labels, and stacks them when the window gets narrow.

tl.config.className = "history"; tl.autoBuild(); // that's all

03Lists that arrive later

        

            autoBuild() only sees the lists on the page when it runs. A list inserted afterwards renders as
            a plain bullet list until refresh() picks it up, optionally scoped to a parent element.
            New entries in a list that is already built need nothing: the styling is class-based.
