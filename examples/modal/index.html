03Per-trigger widths, and one shared stack

        

            config.modalWidthsAttribute lets a single trigger override the responsive widths
            for the modal it opens, without leaking into the next one. And the stack is shared by
            all instances, because the state it protects — the body freeze — belongs to the document.
        

        

            

                
↔

                
Width per trigger

                
Same modal, three triggers, three widths. A trigger without the attribute falls back to the defaults.
