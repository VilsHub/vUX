In the templateBecomes

            
                
data-v-fieldone bar of text, of a varying word-like width

                
<img> <video> <svg> <canvas> …a media block, swapped for a <span> carrying the same class and style, so your sizing still applies

                
<button> <input> <select> <textarea>a filled block of the control's own size

                
static texta bar exactly as long as the words, which stay in place, transparent

                
anything elsekept: your card, its padding, background and layout

                
data-skeleton="text:3"three lines, the last one short

                
data-skeleton="circle"a circle; circle:48 or circle:3rem also sizes it

                
data-skeleton="rect"a filled block; rect:16/9 also sets an aspect ratio

                
data-skeleton="media"a media block, for a <div> with a background image; media:4/3 takes a ratio

                
data-skeleton="keep"left exactly as written — a label that is true before the data arrives

                
data-skeleton="skip"left out — a badge that only some items show

04Mask mode — refreshing what is already there

        

            With no config.template, the skeleton masks the container's own content in
            place. Nothing is cloned: classes go on, text is wrapped in a span so each bar is as long
            as its words, and when the mask lifts the same nodes go back and the markup is
            byte-for-byte what it was — the status line below checks.
