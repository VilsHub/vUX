03Where it renders

        

            Pass the trigger to showProgress(element) and the space is resolved in order: the
            element's data-progress-space attribute (renamed through
            config.dataAttributeNames), then the element itself, then the constructor's default
            space. All three buttons call the same instance.

04Lifecycle

        

            destroy() stops the crawl timer and the grid animation, removes the window
            listeners and every block the instance injected. A destroyed instance cannot be initialized
            again: create a new one.
