01Select and manipulate

$$.ss and $$.sa are querySelector and querySelectorAll. $$.sm wraps an element or a selector: given a selector, hide, unHide and the class methods act on every match, while index, cssStyle and class.has read the first.

02Motion

Slides are CSS transitions the core sets up for you: it adds .vSlide, writes a start value, forces a reflow and writes the end value. In position mode the direction is in the numbers — toLeft and toRight both move x[0] → x[1].

Accordion · toBottom / toTopuse: "dimension"

After the transition the core hands the height back to CSS, so content that grows later — a late image, a wrapped line on resize — is not clipped at the height measured at open time.

toLeft and toRight fill in defaults for use, positions and dimensions. toTop and toBottom do not: leave use out and they take the position branch with no positions, and throw.
