Rings and borders, drawn on canvas.

One constructor, three shapes: a progress ring that animates between values, a marching-ants border, and a fixed dashed border. Sharp on every screen.

reduced motion: animation off
arc().draw(canvas, 87, "deployed")
animatedRectangle / radius 16

A colour that never sits still

config.lineColor is read on every frame, so a tween can write it while the dashes run.

animatedRectangle / counter-clockwise

Square corners, reversed

clockWise = false runs the dashes the other way round.

fixedRectangle

Drawn once, then left alone

A still dashed border for drop zones and placeholders.

const shapes = new CShapes(); shapes.arc(); shapes.animatedRectangle(); shapes.fixedRectangle();

01arc(): the progress ring

Every config property of arc() is wired below; any change redraws the ring. With a duration above 0, each draw animates from the value last shown on this canvas to the new one.

04Many rings at once

        

            A file-upload list: each row has its own arc() object and its own canvas, fed progress in uneven steps.
            Each step animates from where the last one ended, and callback marks the row done at 100.
        

        

        

            
            
            
            
        

    







    

        
05Bad input throws

        

            Every setter and draw() checks its argument and throws at the call, so a typo fails in your code, not
            silently inside an animation frame. Each button below makes one bad call and prints what was thrown.
