02Five ways in

        

            drop, slideLeft and slideRight are driven by the core slide utility,
            $$.sm(el).slide. Each leaves the way it came. The space a message takes in its lane opens and
            closes with the same utility, which is why the others never jump.
        

        

            

                
drop

                
Falls from above

                
Starts just above the window and drops to its place in the lane. On close it rises back out. This is the default.

                

            

            

                
slideLeft

                
From the right edge

                
Travels leftwards to wherever its alignment puts it. A centred one stops in the middle. It leaves back out to the right.

                

            

            

                
slideRight

                
From the left edge

                
The mirror image of slideLeft: comes in from the left and leaves back out through it.

                

            

            

                
fade

                
Quiet

                
A short fade and settle in place. Every other effect falls back to this one when the visitor asks for reduced motion.

                

            

            

                
none

                
Instant

                
No animation at all. A speed of 0 means the same thing with any effect.

                

            

        

    






    

        
03Messages you hold on to

        

            show() returns a handle. Use it to close a message when you decide, rather than when the timer does.
            Content can also be an element, so a message can carry your own controls.
        

        

            

                
duration: 0 + handle.close()

                

                    
A sticky "Saving…" message that stays up until the work it reports on
                        finishes, then gives way to the result.

                    
                

            

            

                
element content

                

                    
The message body is a node of the page's own, with an Undo button wired
                        by the page. Pressing it closes the message through the handle.

04Bad input fails immediately

        

            Every config property and every per-call option is checked when it is set, by the same rule, so a typo
            throws to your code instead of producing a message that silently ignores it.
