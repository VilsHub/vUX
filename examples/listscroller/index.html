vUX / ListScroller / v4.0.0-beta

A row wider than the page, two buttons to move it.

Hand ListScroller a <ul>, the element around it and your own two buttons. It lays the list out in one scrollable row, moves it a step per press, and keeps each button's inactive state matched to where the row really is, however it got there.

new ListScroller(box, list); ls.config.buttons = [prev, next]; ls.initialize(); ls.onScroller();

    02The buttons follow the list
    
        
    
            The row is a real scroll area. Swipe it, use a trackpad or Shift + wheel, or drag the
            frame's corner to make it narrower. ListScroller measures the actual scroll position each time, so the
            buttons never claim there is more to see when there isn't. Items added later widen the row by themselves.

      03No buttons at all
      
        
      
            With config.hasButtons = false ListScroller only does the layout: one row, no wrapping, its
            scrollbar hidden. Swiping, the trackpad and Shift + wheel still scroll it.
            That suits a filter bar on a phone.
